SOC Triage Toolkit

A browser-based toolkit for learning how Security Operations Centre analysts investigate network traffic patterns and Windows security events. All analysis happens locally — your files are never uploaded or transmitted anywhere.

🔒

Privacy by design: All analysis happens entirely inside your browser. Uploaded CSV files are never sent to a server, API, or any external service. No tracking, no cookies, no analytics.

Educational use only. Alerts indicate activity worth investigating and do not prove malicious behaviour. Only analyse traffic and logs from systems and networks you own or are authorised to monitor.

The Central Lesson

“Detection tells an analyst where to look. Investigation determines what actually happened.”

An anomaly is a starting point for investigation, not proof of compromise. Both tools in this toolkit are designed to teach you how to think like a SOC analyst — systematically, with curiosity and healthy scepticism.

What This Toolkit Teaches

Network Analysis

  • How to read Wireshark packet data
  • Why high traffic volume deserves investigation
  • How scanning patterns appear in traffic logs
  • How to distinguish protocols and their roles
  • Why anomalies are not automatic proof of attack

Windows Event Logs

  • What key Windows Event IDs mean
  • How to recognise suspicious authentication patterns
  • Why event correlation matters in SOC work
  • How privilege escalation sequences look in logs
  • Why a single event rarely tells the whole story

Analyst Mindset

  • How to assess investigative priority
  • How to consider benign explanations
  • What “suggested next steps” look like in practice
  • Why thresholds are contextual, not universal
  • How false positives occur and why they matter

How to Use This Toolkit

  1. Choose the tool that matches your data — Network for Wireshark exports, Windows for Event Viewer exports.
  2. Use the Load Sample buttons to explore pre-built scenarios without needing real data.
  3. Upload your own CSV file using the upload area or by dragging and dropping the file.
  4. Review the dashboard summary to understand what was captured.
  5. Read through the findings. Click each alert to expand the full explanation.
  6. Use the filters to focus on specific sources, protocols, accounts, or severity levels.
  7. Adjust detection thresholds if the defaults do not match your environment.
  8. Read the “How to Think Like an Analyst” section in each tool for guidance on investigation.
